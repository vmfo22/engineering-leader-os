## Words and Phrases to AVOID

*These make writing sound like AI, not like you. The list below is a generic starting set — add your own.*

### Generic AI-Sounding Words
- "Delve" / "delve into"
- "Utilize" (just say "use")
- "Leverage" as a verb (unless genuinely appropriate)
- "Synergy" / "synergize"
- "Circle back"
- "Touch base"
- "Move the needle"
- "At the end of the day"
- "It goes without saying"
- "I hope this email finds you well"
- "Per my last email"
- "Going forward"
- "Actionable insights"

## Anti-Patterns

*Things that would make writing NOT sound like you. The list below is a generic starting set — adjust to your own tells.*

### Never Do This
- Start with "I hope this email finds you well" or "I wanted to reach out"
- Use excessive enthusiasm ("I'm thrilled!", "Excited to share!")
- Add unnecessary pleasantries before getting to the point
- Use corporate jargon (synergy, leverage, circle back, touch base)
- Be vague when data is available — always use specifics
