3. Process this inbox to zero at least once per week (during weekly review)

## Processing Guide

During weekly review, process each item:

| If it's... | Move it to... |
|------------|---------------|
| A task for this week | Your task manager / daily note |
| A task for a specific person | That person's file in `people/` |
| An initiative idea | `initiatives/_dashboard.md` |
| A goal or aspiration | Appropriate file in `goals/` |
| A decision to make | `decisions/decision_log.md` |
| A meeting prep item | Appropriate file in `meetings/` |
| Something to remember | `memory.md` |
| Something to think about later | Someday/Maybe section below |
| Something blocked on others | Waiting For section below |
| Not actually important | Delete it |
